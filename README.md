## 📌 Project Overview
The **Prime Video Dashboard** offers a dynamic and interactive overview of the platform's content library, providing deep insights into catalog diversity, content ratings, genre dominance, geographical distribution, and historical library expansion.

## 🎯 Key Performance Indicators (KPIs)
1. **Total Library Metrics:** Detailed breakdown of total titles, unique titles, format splits, and distinct directors.
2. **Rating Breakdown:** Distribution of ratings (`13+`, `16+`, `ALL`, `R`, etc.) reflecting content age appropriateness.
3. **Genre Prevalence:** Identification and ranking of the top genres in the Prime Video catalog.
4. **Geographical Reach:** Regional analysis highlighting country-wise content production volume.
5. **Format Split:** Comparative ratio between **Movies** vs. **TV Shows**.
6. **Library Growth:** Historical timeline tracking title additions and release trends over time.
